# Langkah English V13-C3 · TKA-05 and TKA-06 release

Release prepared: 31 October 2026. Baseline: **the corrected combined V13-C2 source**, which already contains both the V13-C1 homepage redesign and TKA-03/TKA-04. This release does not replace the homepage redesign or change the quiz assessment engine.

## What is included

| Module | Scope | Scaffold steps | Explained cards | Embedded practice | Topic quiz |
|---|---|---:|---:|---:|---:|
| TKA-05 · Implied ideas, audience, purpose and message | Distinguishing stated and implied ideas; combining clues; intended audience; author purpose; broader message; evidence limits | 11 | 10 | 3 | 12 items |
| TKA-06 · Inference, cause, character and prediction | Evidence-based inference; cause/effect chains; character traits and motivation; conditional prediction | 14 | 10 | 3 | 12 items |

Both lessons preserve the Indonesian-first teaching contract and English-first assessments. Each includes four named scaffold phases, a connected 200–300-word guided model, ten distinct bilingual worked examples, three embedded practices, a checkpoint, a written self-check, and Bekal Kosakata last.

Each untimed topic quiz contains two unseen full passages: one A2 editorial target (200–300 words) and one B1 editorial target (250–350 words). Each has four single-answer, four multiple-answer, and four category questions. Questions include exact evidence quotations, Indonesian explanations, and translated prompts/options. A2/B1 labels are editorial targets, not externally calibrated CEFR certifications. These are original unofficial practice materials, not official TKA papers or score predictors.

## Full-passage and inferential readiness

TKA-05 moves beyond locating explicit information: students infer what a text suggests, identify the audience from needs and design, distinguish topic from purpose and message, and support interpretations with clues from multiple paragraphs. TKA-06 asks learners to trace direct and contributing causes, distinguish sequence from causation, infer character traits from patterns of action, and make predictions that retain conditions and uncertainty. The quizzes then test transfer to unseen A2/B1-length passages.

## Installation

Use `langkah-english-v13c3-combined-update-from-v13c2.zip` on top of the **corrected combined V13-C2 repository**, preserving relative paths and `.git`. The patch adds TKA-05/TKA-06 and their quizzes while retaining the redesigned homepage already present in that baseline. Do not apply this patch directly to the original V13-C1 source. Do not extract `langkah-english-v13c3-combined-complete-site.zip` over an existing Git repository; use the complete-site ZIP only for a separate preview/restoration copy.

Run `python3 tools/validate.py` and `for f in tests/*.mjs; do node "$f" || exit 1; done` before committing. Optionally run `python3 tests/v13c3-browser-smoke.py` where Playwright and Chromium are installed. Test both new lessons and quizzes on a real phone, then verify the live deployment after publishing.
