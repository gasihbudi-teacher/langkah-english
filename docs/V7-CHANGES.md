# Langkah English V7 — Patient teaching + organised sections

## Changes
- All 30 published lessons gain a three-stage Indonesian scaffold before dense rules.
- Stages include English sentence examples, Indonesian meanings, and specific explanations.
- Original advanced notes remain available inside an accessible optional details box.
- Each lesson includes a new English-first low-stakes checkpoint (30 total) after basic examples; hints and explanations are in Indonesian.
- Each lesson includes a reflection pause after comparison examples.
- English terms explicitly marked with `[[...]]` show BOTH high-contrast highlighting and quotation marks; quoted words remain visible when colour is unavailable.
- All lesson translation surfaces now use the safe term-formatting helper.
- Each grade has independent collapsible **Materi** and **Latihan** groups; Grammar and UTBK also separate learning and practice.
- Old `school.html?grade=9` and `#grade-9` links remain supported. Deep-linked sections open automatically.
- No server/database needed; the site remains static for Cloudflare Pages.

## Educational limitations
- These are teaching aids, not independently reviewed curriculum materials. Review the new Indonesian scaffolds and the 30 new checkpoint distractors with an English educator.
- V6's eight additional examples are preserved per lesson; two appear in the opening scaffold as intentional reinforcement.
- The original 234 graded questions, answers and choices are unchanged. Guided checks are deliberately not scored or saved.
- Native browser/mobile smoke test is recommended before production deployment.
