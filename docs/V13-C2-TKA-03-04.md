# Langkah English V13-C2 · TKA-03 and TKA-04 release

Release prepared: 31 October 2026. Baseline: the user-confirmed V13-C1 source snapshot plus the separately supplied V13-C1 homepage redesign. This combined release integrates the homepage redesign with the TKA-03/TKA-04 content update; it does not introduce a second redesign or change the assessment engine.

## What is included

| Module | Scope | Scaffold steps | Explained cards | Embedded practice | Topic quiz |
|---|---|---:|---:|---:|---:|
| TKA-03 · Classifying, outlining, summarising and synthesising | Main idea, paragraph roles, supporting details, outline hierarchy, faithful summary, cross-paragraph synthesis | 11 | 10 | 3 | 12 items |
| TKA-04 · Vocabulary, reference and connectors in context | Context clues, reference chains, pronouns/demonstratives, addition, contrast, cause, result, condition and sequence | 10 | 10 | 3 | 12 items |

Both lessons preserve the Indonesian-first teaching contract and use English-first assessment prompts. Each lesson contains a guided, connected 200–300-word, multi-paragraph model after the scaffold, ten distinct bilingual worked examples, three embedded low-stakes practices, a written self-check, and Bekal Kosakata last.

Each untimed topic quiz contains two unseen full passages: one A2 editorial target (200–300 words) and one B1 editorial target (250–350 words), with four single-answer, four multiple-answer and four category questions. Each question has a linked evidence quote and explanation. The difficulty labels are editorial targets, not externally calibrated CEFR certifications. These are original unofficial practice materials, not official TKA papers or score predictors.

## Full-passage readiness gate

The new lessons make the bridge from small examples to full reading explicit. Students practise identifying paragraph roles and mapping evidence across paragraphs before producing an outline, summary or synthesis. In TKA-04 they follow unknown vocabulary, reference chains and connectors across complete passages. The quiz then checks transfer to unseen A2- and B1-length texts rather than introducing long passages only at assessment.

## Installation

Use `langkah-english-v13c2-combined-update-from-v13c1.zip` on top of the accepted V13-C1 repository, preserving relative paths and `.git`. This combined patch includes the homepage redesign, so it can be used whether or not the separate V13-C1 homepage patch was previously applied. Do not extract `langkah-english-v13c2-combined-complete-site.zip` over an existing Git repository. The complete-site ZIP is for a separate preview or restoration copy. Run `python3 tools/validate.py` and `for f in tests/*.mjs; do node "$f" || exit 1; done` before committing. Optionally run `python3 tests/v13c2-browser-smoke.py` where Playwright and Chromium are installed. Test both new modules and quizzes on a real phone, then verify the live deployment after publishing.
